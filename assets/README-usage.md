# CAPRI//NET — Visual assets

Assets vetoriais SVG para o README de perfil do GitHub.

## Arquivos
- `divider-neon.svg`: divisor horizontal.
- `section-identity.svg`: cabeçalho da seção de apresentação.
- `section-tech-stack.svg`: cabeçalho da seção de tecnologias.
- `status-online.svg`: indicador de status.

## Como usar
1. Crie uma pasta `assets` no repositório do seu perfil.
2. Copie os SVGs para essa pasta.
3. Referencie no README com caminhos relativos, por exemplo:

   `![CAPRI//NET](./assets/divider-neon.svg)`

As cores seguem a paleta CAPRI//NET: `#09080D`, `#17101B`, `#FF3B81`, `#FF3155`, `#B44AFF` e `#45DFFF`.

Os SVGs são editáveis: abra qualquer arquivo no VS Code para ajustar cores, dimensões e textos.
